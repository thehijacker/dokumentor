# PaddleOCR (Removed)

PaddleOCR support has been removed from this project due to high memory usage and model size.

- The application now uses **Tesseract** as the sole OCR engine.
- If you require higher-accuracy OCR in the future, consider integrating an external OCR service or a lightweight server-side model that meets your infrastructure constraints.

This file is kept for historical reasons; PaddleOCR-related configuration, volumes, and dependencies have been removed from the codebase.
